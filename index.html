Welcome to Antigravity Logger!

This application demonstrates a lightweight, near-real-time inference SDK wrapper, ingestion pipeline, and logging queue.

💡 Try these test scenarios:

  • Normal Chat: Select a model and start a conversation. Responses stream word-by-word.
  • PII Redaction Test: Type sensitive info like john.doe@example.com or phone 123-456-7890 or standard card numbers 4111 2222 3333 4444. The logs in the dashboard will automatically mask these inputs/outputs!
  • Cancellation Test: Click the Stop button while a long response is streaming to test mid-flight cancels.
  • Error Logging: Send a message containing the phrase trigger error. The mock provider will fail, and you'll see the HTTP error tracked live on the dashboard.
